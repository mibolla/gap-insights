# GAP-Insights

Gesundheit und Alter – Gemeinde für Gemeinde. Kennzahlen zu Bevölkerung, Spitex und Pflegeheimen
für alle Gemeinden der Schweiz.

**App:** https://mibolla.github.io/gap-insights/

Daten: BFS (STATPOP, BEVNAT), BAG (Kennzahlen Pflegeheime und Spitex), swisstopo · Open Government Data.
Datenstand: 2026-11-12. Diese Seite wird automatisch aus dem Projekt erzeugt (`scripts/publish_app.sh`),
bitte hier nichts von Hand ändern.
